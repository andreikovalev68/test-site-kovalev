# Сайт Андрея Ковалева (Andre) – певец, композитор, продюсер

Сайт артиста kovalevandre.ru: песни, жанр, творческий путь, сцена и партнёры, программы, авторские проекты, контакты. Две версии – русская и английская.

## Состав
- `index.html` – русская версия.
- `en/index.html` – английская версия (кнопки EN / RU в шапке).
- `style.css` – общие стили для обеих версий.
- `img/` – фото, обложки и иконки; `img/docs/` – сканы грамот (большие и `-mini` превью; в письме Минобороны закрыт адрес).
- `audio/otbivka.mp3` – джингл «Андрей Ковалев» для кнопки «Отбивка».
- `site.js` – кнопка «Отбивка», просмотр грамот, меню на телефоне.
- `img/og.jpg` – картинка-превью для соцсетей; `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` – иконки сайта.
- `robots.txt`, `sitemap.xml` – служебные файлы для поисковиков (адреса пока http – сменить на https после выпуска сертификата).
- `фото/` – исходные фотографии и обложки в полном размере.
- `CNAME` – домен kovalevandre.ru для GitHub Pages.
