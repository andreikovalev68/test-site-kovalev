# Сайт Андрея Ковалева – певец, композитор, продюсер

Одностраничный сайт артиста: песни, жанр, творческий путь, сцена и партнёры, программы, авторские проекты, контакты.

## Как открыть
Скачайте репозиторий и откройте `index.html` двойным щелчком – сайт откроется в браузере.

## Состав
- `index.html` – весь сайт в одном файле (стили и фото встроены внутрь).
- `фото/` – исходные фотографии и обложки в полном размере.

## Бренд
Тёмный фон `#13161B`, золото `#D9A75C`, светлый текст `#F3F1EC`.
Шрифты: Cormorant Garamond (заголовки) и Golos Text (текст).
